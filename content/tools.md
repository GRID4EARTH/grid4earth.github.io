These tools share one principle: a single equal-area grid for Copernicus and Destination Earth data. [`healpix-geo`](https://healpix-geo.readthedocs.io/) provides the core coordinate algorithms on the WGS84 ellipsoid; the others build on it for resampling, analysis, plotting and 3D visualization. Each links straight to its own documentation.
